## Boundaries of this organization

- All original tracked files are accounted for by an original-to-current path and original SHA-256 in the inventory. Files requiring path/import changes are identified; data/results/raw artifacts remain byte-identical.
- Names of datasets, criteria, model labels, response fields and workbook labels are retained as experimental identifiers. Human comments, story text, provider payloads, historical notes and third-party source are not rewritten to improve prose, since they are evidence.
- Per-profile demonstration JSONs are derived by exact extraction from the original combined file. The original combined file is retained; the verifier checks equality of demonstration values.
- New RQ1/RQ3 entry points and the all-analysis command only orchestrate existing analysis logic. New verification/provenance utilities are labeled as package-maintenance tools, not original research procedures.
- No sample selector, seed, confidence calibration estimator, human-coding algorithm, or unverified claim of AI involvement in human reference construction has been introduced. The later RQ3 stable-error script implements the study owner's supplied counting definition and writes newly computed verification outputs separately.
