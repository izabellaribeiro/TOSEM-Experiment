# Historical documentation

Files in this directory retain their original contents for provenance, including outdated paths, proposed seven-RQ numbering, earlier model choices, and pre-adjudication Gold Standard counts. They are not current reproduction instructions.

Use the root README and [REPRODUCIBILITY.md](../REPRODUCIBILITY.md) for the four-RQ package. Conflicts and missing historical evidence are listed in [MANUAL_REVIEW.md](../MANUAL_REVIEW.md). Original filenames and hashes are recorded in `docs/provenance/artifact_inventory.csv`.
